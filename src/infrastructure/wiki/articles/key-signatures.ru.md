Когда в пьесе всё время встречаются одни и те же диезы или бемоли, их не пишут перед каждой нотой.
Их ставят один раз в начале каждой строки нотоносца — сразу после ключа и перед размером; размер
пишут только в начале первой строки. Эти знаки называются **знаками при ключе**.

Знак при ключе действует на все ноты своей ступени во всех октавах, пока не сменится
тональность. Ноте, которую альтерирует знак при ключе, собственный знак не ставят.

```staff Один диез при ключе: ноты на его ступени звучат с диезом в обеих октавах без собственного знака
4/4 1# F4/half F5/half
```

Диезы всегда идут в одном и том же порядке: :note[F#4], :note[C#4], :note[G#4], :note[D#4],
:note[A#4], :note[E#4], :note[B#4]. Бемоли — в обратном: :note[Bb4], :note[Eb4], :note[Ab4],
:note[Db4], :note[Gb4], :note[Cb4], :note[Fb4]. Знаки не пропускаются: три диеза при ключе — это
всегда :note[F#4], :note[C#4] и :note[G#4].

```staff Семь диезов по порядку
4/4 7# C5/whole
```

```staff Семь бемолей по порядку
4/4 7b C5/whole
```

У каждого знака своё место на нотоносце. Первый диез стоит на верхней линейке, линейке ноты
:note[F5]; первый бемоль — на средней линейке, линейке ноты :note[B4].

```staff Два диеза: ноты на их ступенях звучат с диезом, остальные без знаков
4/4 2# D4/quarter F4/quarter A4/quarter C5/quarter
```

```staff Три бемоля: ноты на их ступенях звучат с бемолем, остальные без знаков
4/4 3b E4/quarter G4/quarter A4/quarter B4/quarter
```

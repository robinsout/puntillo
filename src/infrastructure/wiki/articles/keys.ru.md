Знаки при ключе принадлежат **тональности**. У разных мажоров разные знаки при ключе, поэтому по ним
можно узнать, какой это мажор. Нота, по которой названа тональность, — её **тоника**.

Чтобы узнать мажор по диезам, возьмите последний диез при ключе: это седьмая ступень мажора, а
тоника на полутон выше. Три диеза — это :note[F#4], :note[C#4] и :note[G#4]; последний —
:note[G#4], на полутон выше — :note[A4], значит, тональность — :note[A4] мажор.

```staff Три диеза: мажор, тоника которого на полутон выше последнего диеза
4/4 3# A4/whole
```

Чтобы узнать мажор по бемолям, возьмите предпоследний бемоль: он называет тонику. Три бемоля — это
:note[Bb4], :note[Eb4] и :note[Ab4]; предпоследний — :note[Eb4], значит, тональность —
:note[Eb4] мажор. Есть два исключения: без знаков — :note[C4] мажор, с одним бемолем —
:note[F4] мажор.

```staff Три бемоля: мажор, тонику которого называет предпоследний бемоль
4/4 3b E4/whole
```

```staff Один бемоль: исключение, которое надо запомнить
4/4 1b F4/whole
```

Те же знаки при ключе есть и у минора — **параллельного минора**. Его тоника на малую терцию ниже
тоники мажора, на шестой ступени мажора: у :note[A4] мажора и :note[F#4] минора одни и те же
знаки, у :note[C4] мажора и :note[A4] минора — тоже.

```staff Те же три диеза: тоника параллельного минора
4/4 3# F4/whole
```

Мажор это или параллельный минор, одни знаки при ключе не говорят. Это решает музыка — на какой
звук она опирается.

# Puntillo

Веб-тренажёр чтения нот с листа. Vue 3 + TypeScript.

- Техническое задание: [`docs/spec.md`](docs/spec.md)
- Правила работы над проектом: [`CLAUDE.md`](CLAUDE.md)
- Критерии приёмки фич: [`docs/features/`](docs/features/)

## Требования

Node.js версии из `.nvmrc` (24.18.0). Версия по умолчанию в системе может быть ниже, тогда:

```sh
nvm use
```

## Установка

```sh
npm install
```

## Команды

| Команда                 | Назначение                                                      |
| ----------------------- | --------------------------------------------------------------- |
| `npm run dev`           | Дев-сервер на http://localhost:5173                             |
| `npm run build`         | Продакшен-сборка с проверкой типов                              |
| `npm run preview`       | Просмотр собранной версии                                       |
| `npm run type-check`    | Проверка типов                                                  |
| `npm run lint`          | Линтеры с автоисправлением                                      |
| `npm run lint:check`    | Линтеры без изменений файлов                                    |
| `npm run format`        | Форматирование                                                  |
| `npm run format:check`  | Проверка форматирования                                         |
| `npm run test:unit`     | Модульные и компонентные тесты в режиме наблюдения              |
| `npm run test:unit:run` | То же однократно                                                |
| `npm run test:coverage` | Тесты с покрытием, домен обязан быть покрыт полностью           |
| `npm run test:e2e`      | Сквозные тесты Playwright                                       |
| `npm test`              | Полная проверка: типы, линтеры, форматирование, модульные тесты |

## Структура

```
src/
  domain/          музыкальные правила, сущности, именование. Чистый TypeScript
  application/     сценарии: сессия, генерация вопроса, проверка, статистика
  infrastructure/  хранилище, i18n, рендер нотации, звук
  presentation/    Vue-компоненты, роутинг, стили
e2e/               сквозные тесты
docs/              техническое задание и критерии приёмки фич
```

Направление зависимостей `presentation → application → domain ← infrastructure`
проверяется правилом `no-restricted-imports` в `eslint.config.ts`.

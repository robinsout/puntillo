# Фича: Вопросы из нескольких нот

Статус: утверждено

Разделы ТЗ: 5.1, 6.1 (длина вопроса, размер, паузы, точки), 6.2, 7.1, 7.2, 7.4, 17

## Зачем

Ноты читают не по одной, а фразами. Вопрос из нескольких нот и тактов учит
читать подряд, видеть ритм такта, паузы и точки.

## Критерии приёмки

### Параметры и пресеты

1. В разделе «Rhythm» панели «Customize» появляются параметры:
   - «Question length»: «One note», «2–4 notes», «One bar», «Two bars»;
   - «Time signatures»: галки 4/4, 3/4, 2/4, 6/8, нужна хотя бы одна;
   - «Rests»: галка;
   - «Dots»: галка.
2. Пресеты получают значения по ТЗ 6.2 полностью:

   | Параметр      | First steps | Confident reading | Advanced  |
   | ------------- | ----------- | ----------------- | --------- |
   | Длина вопроса | одна нота   | один такт         | два такта |
   | Размер        | 4/4         | 4/4, 3/4          | все       |
   | Паузы         | выкл        | вкл               | вкл       |
   | Точки         | выкл        | выкл              | вкл       |

3. Несовместимые значения недоступны с подписью причины, как в срезах панели:
   например, «One bar» в 3/4 при единственной длительности «1/1» — «Doesn't
   fit the time signature».

### Вопрос

4. Размер вопроса выбирается случайно из отмеченных. В вопросе «One bar» и
   «Two bars» сумма длительностей каждого такта равна размеру. «2–4 notes» —
   от двух до четырёх нот в одном такте, такт может быть не заполнен.
5. В вопросе не больше 16 нот и пауз вместе: если параметры допускают больше,
   длительности укрупняются.
6. При включённых паузах в вопросе встречаются паузы разрешённых длительностей.
   Паузы не требуют ответа и не стоят баллов.
7. При включённых точках встречаются ноты и паузы с точкой.
8. На узком экране длинный вопрос переносится на следующую строку нотоносца,
   так что на каждую ноту приходится не меньше 44 px по ширине.

### Ответ

9. Текущая нота подсвечена на нотоносце (не только цветом). Сначала текущая —
   первая нота.
10. Пользователь выбирает название и, если длительность спрашивается,
    длительность. Когда у текущей ноты есть всё, подсветка переходит к
    следующей ноте без ответа справа; паузы пропускаются.
11. Кнопки «Previous note» и «Next note» переводят подсветку на соседнюю ноту.
    Нажатие на ноту на нотоносце делает её текущей. Выбор у ранее отвеченной
    ноты можно изменить.
12. Под каждой отвеченной нотой на нотоносце подписан введённый ответ:
    «sol 1/4».
13. Кнопка точки «Dot» рядом с рядом длительностей (только при включённых
    точках) — переключатель, добавляет точку к выбранной длительности.
14. «Check» проверяет весь вопрос. Если не у всех нот есть ответ — подсказка
    «Answer every note», ответ не принимается.

### Результат

15. Каждая нота стоит два балла (один, если длительность не спрашивается),
    только по первой попытке. Вопрос верен, если верны все ноты; серия считает
    такие вопросы.
16. Ошибки в первой попытке: неверные ноты помечены на нотоносце, «Incorrect.
    Try again.». Вторая попытка — только по помеченным нотам и только по
    неверным частям; остальное закреплено.
17. После второй попытки (или сразу, если включено «Show the right answer at
    once») — разбор по каждой ноте, неверной в последней попытке, с её
    номером: «Note 2: You chose re. This is sol: the note on the 2nd line. You
    chose a quarter note. This is a half note.»
18. Длительность с точкой засчитывается только с точкой.

### Быстрый режим

19. Вопрос проверяется сам, когда ответ получила последняя нота без ответа.
    Дальше как сейчас: верно — следующий вопрос, ошибка — вторая попытка,
    которая тоже проверяется сама после ответа на все помеченные ноты.

### Граничные и ошибочные случаи

1. Вопрос из одной ноты выглядит и работает как сейчас: без кнопок
   перехода и без подписи ответа под нотой.
2. Кнопки перехода недоступны на краях вопроса.
3. Подсветка, пометки и подписи читаются скринридером: у нотоносца текстовое
   описание текущей ноты и ответов.
4. Кнопки ≥ 44×44, нотоносец и кнопки помещаются в 360 px без горизонтальной
   прокрутки.

## Предположения, требующие подтверждения

- Критерий 4: «2–4 notes» укладываются в один такт и не обязаны его
  заполнять.
- Критерий 8: ради цели нажатия ≥ 44 px на 360 px вопрос из двух тактов
  может занять три строки нотоносца.
- Критерий 10: после ответа подсветка идёт к следующей ноте без ответа
  справа; если таких нет — остаётся на месте.
- Критерий 13: точка — отдельная кнопка-переключатель, как в ТЗ 5.1; на
  кнопках длительностей дробь не меняется.
- Критерий 16: в нотах со второй попыткой верная часть (название или
  длительность) закреплена, как в вопросе из одной ноты.

## Вне рамок фичи

- Управление с физической клавиатуры: стрелки и Enter (ТЗ 5.3).
- Очередь повторов (ТЗ 7.3).
- Ноты в нескольких голосах, лиги, триоли.

## Решения по ходу работы

- 2026-10-09: ответы человека перед черновиком. В фичу входят длина вопроса,
  размер, паузы и точки. Текущая нота подсвечена на нотоносце, ответ вводится
  по одной ноте слева направо, есть кнопки перехода к соседней ноте, ноту
  можно выбрать нажатием. В быстром режиме вопрос проверяется после ответа на
  последнюю ноту. Вопрос верен, только если верны все ноты; серия — по
  вопросам.
- 2026-10-09: фича утверждена человеком вместе с пятью предположениями.
  Нарезка — пять срезов.
- 2026-10-09: решения при реализации среза 1. Срезы 1 и 2 вливаются вместе:
  без среза 2 вопрос из нескольких нот в быстром режиме нельзя проверить. Ноты
  в такте стоят на равных расстояниях, чтобы цель нажатия была не меньше
  44 px. Подсветка уходит дальше, только когда нота отвечена впервые. Во
  второй попытке переходы — только по помеченным нотам. Соседние ноты не
  повторяют высоту; целой в вопросе из нескольких нот нет. Цели нот — кнопки
  «Note N» с `aria-current`; четыре состояния различаются рамкой. Подпись под
  нотой — только при полном ответе. После результата можно перейти к неверным
  нотам и посмотреть пометки.
- 2026-10-09: решения при реализации среза 2. Быстрый режим почти целиком
  заработал уже в срезе 1; новое — включение или выключение галки посреди
  вопроса сбрасывает незакреплённый выбор у всех нот и возвращает подсветку на
  первую открытую ноту. Фокус — по общему правилу: нажатая кнопка, иначе
  ближайшая доступная того же ряда, иначе первая доступная другого ряда.
- 2026-10-09: решения при реализации среза 3. Размер доступен, если вопрос
  собирается хотя бы в одном отмеченном размере (ТЗ 6.1 — запрещено только
  пустое множество вопросов). Живой пример в панели рисуется в одну строку.
  Сохранённые настройки прежних версий не мигрируют: у карточки будет
  «Modified». Ключ — в начале каждой строки, размер — только в первой. Первая
  нота строки отступает от знаков на полслота, чтобы цель нажатия не
  заходила на ключ и размер.

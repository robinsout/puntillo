# Фича: Узнавание одной ноты по нотации

Статус: готово

Разделы ТЗ: 5.1, 4.1, 4.2, 6.1 (диапазон высот, длина вопроса), 7.2, 7.4, 12.1, 12.2, 15.1

## Зачем

Начинающий должен уметь посмотреть на знак на нотоносце и назвать ноту. Это
самое первое умение, без которого остальные механики бессмысленны. Фича даёт
пользователю работающий цикл «вижу ноту — называю — узнаю, верно ли».

## Критерии приёмки

1. Пользователь открывает тренажёр → видит нотоносец со скрипичным ключом,
   размером 4/4 и одной нотой в диапазоне C4–C5. Нота стоит на своём месте
   нотоносца, положение не зависит от инструмента.
2. Пользователь видит ряд кнопок с названиями семи ступеней в слоговой системе
   латиницей: do, re, mi, fa, sol, la, si.
3. Пользователь нажимает кнопку названия → кнопка отображается как выбранная,
   остальные как невыбранные.
4. Пользователь нажимает другую кнопку названия → выбранной становится она,
   предыдущая перестаёт быть выбранной.
5. Пользователь нажимает «Проверить» при выбранном верном названии → видит
   сообщение о верном ответе.
6. Пользователь нажимает «Проверить» при выбранном неверном названии → видит
   сообщение о неверном ответе. Сообщение содержит только слово «неверно»,
   правильный ответ не показывается.
7. Пользователь нажимает «Далее» после сообщения о результате → видит новый
   вопрос с одной нотой, выбор названия сброшен, сообщение убрано.
8. Пользователь проходит подряд несколько вопросов → встречает разные ноты, а не
   одну и ту же каждый раз.
9. Результат ответа передаётся не только цветом: сообщение содержит текст.
10. Пользователь видит рядом с кнопкой «Далее» галку «Автоматически открывать
    следующий вопрос». При первом открытии тренажёра она выключена.
11. Пользователь включает галку и проверяет ответ → через 1,5 секунды после
    сообщения о результате видит новый вопрос без нажатия «Далее», выбор
    названия сброшен, сообщение убрано.
12. Пользователь выключает галку → следующий вопрос снова открывается только
    кнопкой «Далее».
13. Язык интерфейса определяется по браузеру. Если язык браузера не русский,
    не английский и не испанский, интерфейс на английском.

### Граничные и ошибочные случаи

1. Если пользователь нажимает «Проверить», не выбрав названия → ответ не
   принимается, сообщение о результате не появляется, пользователю показывается
   подсказка выбрать название.
2. Если пользователь нажимает кнопку названия после показа сообщения о
   результате и до нажатия «Дальше» → выбор не меняется, сообщение остаётся.
3. Если пользователь нажимает «Проверить» повторно на том же вопросе → состояние
   не меняется, повторное сообщение не добавляется.
4. Все интерактивные элементы имеют область нажатия не меньше 44 на 44
   логических пикселя, нотоносец умещается по ширине на 360 пикселях без
   горизонтальной прокрутки.

## Вне рамок фичи

- Ввод длительности и кнопки длительностей.
- Ввод высоты клавиатурой фортепиано и управление с физической клавиатуры.
- Альтерации, ключевые знаки, октавы кроме первой, паузы.
- Вопросы длиннее одной ноты и навигация между нотами вопроса.
- Баллы, точность, серия верных ответов.
- Вторая попытка, разбор ошибки, показ правильного ответа, ссылки в вики.
- Очередь повторов.
- Сессия: режимы, счётчик вопросов, итог, продолжение после перезагрузки.
- Пресеты и панель настройки сложности.
- Звук.
- Сохранение прогресса и статистики.
- Переключение языка и системы именования в интерфейсе.
- Сохранение состояния галки автоперехода между перезагрузками.
- Настройка «показывать правильный ответ при ошибке» — вводится вместе с
  панелью настроек отдельной фичей.

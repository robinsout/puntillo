# Фича: MIDI-клавиатура

Статус: утверждено

Разделы ТЗ: 3.1, 3.2, 5.1, 7.1 (исключение для клавиатуры), 11 (способ ввода), 13 (устройства
ввода), 20

## Зачем

У многих, кто учится читать ноты, дома есть цифровое пианино или MIDI-клавиатура. Отвечать на
настоящих клавишах — это и есть навык, ради которого читают ноты: увидел ноту — нажал клавишу.
Фича позволяет отвечать в «Read notes» клавишами подключённого MIDI-инструмента.

## Критерии приёмки

### Включение

1. При «Piano keyboard» на стартовом экране, под «Play the keys», — галка «Use a MIDI keyboard»,
   по умолчанию выключена. Выбор сохраняется, как остальные настройки, и попадает в экспорт.
   При «Note names» и «Write notes» галка скрыта, значение сохраняется.
2. Включение галки запрашивает у браузера доступ к MIDI (браузер может показать свой вопрос).
   Если галка была включена раньше, доступ запрашивается при открытии приложения.
3. Под галкой — строка состояния:
   - доступ есть и инструмент подключён — «MIDI: Yamaha P-45» (имя инструмента; несколько —
     через запятую);
   - доступ есть, инструментов нет — «Connect a MIDI keyboard to this device.»;
   - доступ не дан — «The browser didn't allow MIDI. Allow it in the site settings.»;
   - браузер не поддерживает MIDI (Safari) — «This browser can't use MIDI keyboards. Try Chrome,
     Edge or Firefox.», галка неактивна.
     Подключение и отключение инструмента меняют строку сразу, без перезагрузки.

### Ответ клавишей инструмента

4. В вопросе «Read notes» при «Piano keyboard» и включённом MIDI нажатие клавиши инструмента —
   то же, что нажатие этой клавиши на экранной клавиатуре: выбирает высоту текущей ноты, клавиша
   выделяется на экране, дальше длительность кнопками или цифрами и «Check» или `Enter`. Быстрый
   режим — как у экранной клавиатуры.
5. Проверка — по звучанию и с октавой, как у экранной клавиатуры (ТЗ 7.1, исключение): чёрная
   клавиша верна и для до♯, и для ре♭; разбор называет точную запись ноты.
6. Нота инструмента вне экранной клавиатуры тоже считается ответом — неверным: разбор называет
   её («You played do2. This is sol4: the note on the 2nd line.»). На экране ничего не выделено.
7. При включённом MIDI под его галкой — галка «Play sound for the MIDI keys», по умолчанию
   выключена (цифровое пианино звучит само), выбор сохраняется и попадает в экспорт. Включена —
   нажатие клавиши инструмента звучит фортепиано тренажёра, как экранная клавиша; выключена — не
   звучит. Галка «Play the keys» по-прежнему отвечает только за экранную клавиатуру и клавиатуру
   компьютера.
8. Клавиша, неактивная на экране (отклонённая в первой попытке, высота уже засчитана, вопрос
   проверен), с инструмента ничего не делает.
9. Экранная клавиатура и клавиатура компьютера работают как раньше, вместе с MIDI.
10. На экране вопроса над клавиатурой — та же строка состояния MIDI мелким текстом, чтобы было
    видно, подключён ли инструмент.

### Вики

11. В статье «The piano keyboard» — абзац об ответе с MIDI-клавиатуры: как подключить, что

12. Все новые тексты на русском, английском и испанском (см. «Тексты»).

### Граничные и ошибочные случаи

1. Аккорд (несколько клавиш одновременно) → каждая клавиша — отдельное нажатие по порядку
   прихода: в вопросе из нескольких нот они заполняют ноты одну за другой.
2. Отпускание клавиши, педаль, колесо высоты и прочие сообщения инструмента → ничего.
3. Инструмент отключён посреди вопроса → строка состояния меняется, уже выбранный ответ остаётся.
4. Нажатие на инструменте, когда на экране не вопрос «Read notes» (стартовый экран, итог, вики,
   «Write notes») → ничего.
5. Галку выключили → тренажёр перестаёт слушать инструмент сразу.
6. Открыта подсказка вики или диалог «Keyboard shortcuts» → нажатия инструмента ничего не делают.
7. Звук MIDI включён, но на странице ещё не было ни одного нажатия или касания → браузер не даёт
   начать звук, нажатия инструмента молчат до первого щелчка или нажатия на странице (сэмплы
   грузятся по нему, как у экранной клавиатуры).

## Предположения, требующие подтверждения

1. Нажатием считается сообщение «нота включена» с ненулевой силой на любом канале любого
   подключённого входа; номер ноты MIDI = номер клавиши (до4 = 60).
2. Строка состояния (критерий 10) показывается на экране вопроса только при включённом MIDI.
3. Доступ запрашивается без системных сообщений (SysEx) — тогда в Chrome вопрос браузера проще или
   не задаётся вовсе.
4. Firefox запрашивает доступ к MIDI через установку «дополнения сайта» — это поведение браузера,
   тренажёр показывает свою строку состояния по результату.

## Вне рамок фичи

- MIDI в «Write notes» (там важна запись, а клавиша её не задаёт).
- Длительность по тому, сколько держали клавишу, игра в темпе (ТЗ §20, метроном).
- Выбор конкретного входа и канала, транспонирование, настройка чувствительности.
- Вывод звука на MIDI-инструмент.

- 2026-10-14: ответы человека перед черновиком — MIDI включается галкой при «Piano keyboard», а не
  отдельным способом ввода; нота вне экранной клавиатуры считается (неверным) ответом; звук
  тренажёра на нажатия инструмента не играет.
- 2026-10-14: правка человека при утверждении — звук тренажёра для клавиш MIDI включается
  отдельной галкой «Play sound for the MIDI keys» (по умолчанию выключена): у MIDI-клавиатуры может
  не быть динамиков. Фича утверждена вместе с четырьмя предположениями и нарезкой на три среза.
- 2026-10-14: решения при реализации среза 1 (без эскалации). Входы слушаются через
  `onmidimessage` (Chrome открывает порт сам, повторной подписки не бывает). Аккорд при
  спрашиваемой длительности: каждая следующая клавиша заменяет высоту текущей ноты — курсор идёт
  дальше только после высоты и длительности. Нажатие инструмента и щелчок по экранной клавише идут
  одним путём (`answerWithKey`), отличается только звук. Доступ к MIDI запрашивается в `App.vue` при
  открытии с сохранённым флагом — на любом экране. Сквозные тесты подменяют Web MIDI фейковым
  входом; проверка на настоящем инструменте — за человеком.

# Фича: Дроби на кнопках длительностей

Статус: утверждено

Разделы ТЗ: 5.1 (ввод длительности)

## Зачем

На кнопках длительностей нарисованы те же ноты, что и на нотоносце. Чтобы
ответить, достаточно найти такую же картинку: длительность читать не нужно.
Дробь на кнопке заставляет назвать длительность, а не сравнить рисунки.

## Критерии приёмки

1. Кнопки длительностей в тренажёре подписаны дробью вместо рисунка ноты:
   «1», «1/2», «1/4», «1/8», «1/16». Подписи одинаковы на трёх языках.
2. Доступное имя кнопки совпадает с видимой подписью.
3. В панели «Customize» у галок длительностей вместо рисунка — та же дробь
   после названия: «Quarter note 1/4».
4. Разбор ошибки не меняется: «You chose a quarter note. This is a half
   note.»
5. Остальное поведение кнопок — выбор, пометки, вторая попытка, быстрый
   режим, фокус — без изменений.

### Граничные и ошибочные случаи

1. Кнопки ≥ 44×44, ряд из пяти кнопок помещается в 360 px.
2. Дробь не зависит от шрифтов с музыкальными символами.

## Вне рамок фичи

- Изменение рисунков нот на нотоносце.

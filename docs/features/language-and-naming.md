# Фича: Выбор языка и системы названий нот с сохранением

Статус: утверждено

Разделы ТЗ: 12.1, 12.2, 11 (настройки интерфейса, недоступное хранилище)

## Зачем

Сейчас язык берётся только из браузера, а ноты всегда называются do, re, mi.
Человек, который учился по «до, ре, ми» или по «C, D, E», должен видеть
привычные названия, а выбранные язык и настройки не должны сбрасываться при
каждом открытии страницы.

## Критерии приёмки

### Язык интерфейса

1. На экране выбора длины есть список «Language» с вариантами English,
   Русский, Español. Названия языков написаны на самих языках и не
   переводятся. Выбранным показан текущий язык.
2. Пользователь выбирает язык → весь интерфейс сразу переходит на него, без
   перезагрузки страницы. Атрибут `lang` страницы меняется вместе с ним.
3. Пока пользователь не выбирал язык, он определяется по браузеру, как сейчас.
   После выбора сохранённый язык важнее языка браузера.

### Система названий нот

4. Рядом есть список «Note names» с тремя вариантами: «do, re, mi», «до, ре,
   ми», «C, D, E». По умолчанию выбран «do, re, mi».
5. Выбранная система применяется к кнопкам названий и к тексту разбора ошибки:
   «Вы выбрали ре. Это соль — нота на второй линейке.»
6. Система выбирается независимо от языка: смена языка не меняет систему, смена
   системы не меняет язык.
7. При выборе «C, D, E» появляется переключатель седьмой ступени «B» / «H», по
   умолчанию «B». При «H» кнопка и разбор называют си буквой H. При других
   системах переключатель скрыт, но его значение помнится.

### Сохранение

8. Сохраняются между перезагрузками страницы: язык (если выбран вручную),
   система названий, B или H, галка «Show the right answer at once» и галка
   «Open next question automatically». Каждое значение сохраняется в момент
   изменения.

### Граничные и ошибочные случаи

1. Хранилище браузера недоступно или переполнено → тренажёр работает, выбор
   действует до перезагрузки. На экране выбора длины под настройками одна
   строка: «Settings won't be saved in this browser.» Модальных окон и
   повторных уведомлений нет.
2. В хранилище лежит повреждённое или неизвестное значение → оно
   игнорируется, используется значение по умолчанию, ошибки пользователь не
   видит.
3. Списки и переключатель доступны с клавиатуры, имеют подписи для
   скринридера, область нажатия не меньше 44×44, экран выбора помещается в
   360 px без горизонтальной прокрутки.

## Предположения, требующие подтверждения

- Критерий 1 и 4: обычные выпадающие списки (`<select>`), B/H — пара
  радиокнопок.
- Критерий 3: если язык не выбирали вручную, он каждый раз определяется по
  браузеру и не сохраняется.
- Критерий 7: при «H» меняется только седьмая ступень, остальные буквы те же.
- Граничный случай 1: строка видна всё время, пока открыт экран выбора, и не
  закрывается крестиком.

## Вне рамок фичи

- Названия альтераций (C♯, до-диез, do sostenido) и правило «B = си-бемоль при
  H» — вместе с фичей, которая вводит альтерации.
- Панель настроек (ТЗ 6.3) и отдельный экран настроек.
- Смена языка и системы во время вопроса и на итоге.
- Сохранение статистики, истории и незавершённой сессии.
- Экспорт и импорт.

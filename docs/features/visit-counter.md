# Фича: Счётчик посещений

Статус: черновик

Разделы ТЗ: вне MVP (раздел 3 счётчик не упоминает), 13 (порт), 18 (размер сборки, время до взаимодействия)

## Зачем

Автору нужно знать, сколько людей пользуются тренажёром и какими его частями, без cookies, IP и сторонних скриптов.
Используется собственный счётчик `robinsout/counter`, общий для проектов аккаунта.

## Критерии приёмки

1. Пользователь открывает экран (тренажёр, прогресс, настройки, вики, статья вики) → на сервер уходит событие
   `view` с фиксированным id экрана и языком интерфейса. Ничего другого из адреса не отправляется.
2. Пользователь начинает сессию → уходит событие `session` с механикой (`m1`/`m2`) и пресетом
   (один из трёх или `custom`).
3. Пользователь доходит до итога сессии → уходит событие `summary` с механикой, баллами и максимумом.
4. Пользователь открывает статью вики → в `view` идёт id статьи только из списка `WIKI_TOPICS`;
   неизвестная статья отправляется как `unknown`.
5. В настройках есть переключатель «Не считать мои визиты». Включён → событий нет ни в Puntillo, ни в других
   проектах аккаунта на `robinsout.github.io` (ключ `robinsout-counter-off` общий). Состояние видно
   после перезагрузки.
6. Браузер передаёт Global Privacy Control → событий нет, переключатель при этом ничего не меняет.
7. Дев-сервер, модульные и сквозные тесты, Lighthouse в CI → событий нет: адрес сервера задаётся только при сборке
   для публикации.
8. Сервер счётчика недоступен → приложение работает как обычно, ошибок пользователь не видит.

### Граничные и ошибочные случаи

1. Если `localStorage` недоступен → переключатель не запоминается. **Вопрос 3.**
2. Если пользователь импортирует прогресс → флаг «не считать» не входит в экспорт и импорт (он общий
   для всех проектов, а не принадлежит Puntillo).

## Вне рамок фичи

- Страница статистики: она живёт в `robinsout/counter`.
- События отдельных ответов, ошибок и нажатий клавиш.
- Изменения клиента и сервера счётчика, кроме записи Puntillo в `projects.json`.

## Вопросы на утверждение

1. **Набор событий.** Предлагаю `view`, `session`, `summary` (критерии 1–3). Достаточно, больше или меньше?
2. **Где переключатель.** Предлагаю раздел настроек, отдельный блок «Конфиденциальность» с одним
   переключателем и строкой «Без cookies и IP; учитываются день, тип устройства и экран». Тексты на трёх языках.
3. **Хранилище недоступно.** Переключатель скрыть, показать неактивным с пояснением или оставить
   без запоминания?
4. **README.** Добавить раздел о том, что считается и как выключить (по-английски)?

## Решения по ходу работы

- 2026-10-20: клиент `client/counter.ts` из `robinsout/counter` копируется в `src/infrastructure/analytics/`
  без загрузки с сервера: у Pages-сайтов аккаунта общий origin и общий `localStorage`. Зависимостей нет,
  размер около 1 КБ, лицензия PolyForm NC, как у Puntillo. Готовой библиотеки не берём: счётчик общий
  для проектов аккаунта и уже работает на своём сервере.
- 2026-10-20: в `application/ports` появляется порт аналитики с фиксированными событиями.
  Адаптер — в `infrastructure`, сборка — в `src/main.ts`, в тестах — заглушка.
- 2026-10-20: CSP в Puntillo сейчас нет. Поэтому `connect-src` добавлять некуда, и новую CSP эта фича не вводит.

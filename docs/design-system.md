# Дизайн-система «Нотная бумага»

Единый источник оформления Puntillo. Фича и критерии — `docs/features/design-system.md`, макеты
направления A — https://claude.ai/artifact/9viVShMqQhwxhuRf7W2NvC. Живой каталог — страница
`/design-system` в дев-сервере (`npm run dev`), в рабочую сборку не входит.

## Правила

1. Экран собирается из компонентов системы и токенов. Значения (цвета, размеры, отступы,
   скругления, тени) пишутся только в `src/presentation/ui/tokens.css`; в остальных стилях — только
   `var(--…)`. Это проверяет stylelint (`npm run lint:check`, хук перед коммитом, CI): hex,
   функции цвета, именованные цвета и `px` вне `tokens.css` запрещены; `px` допустим только в
   медиазапросах по ширине.
2. Нужного компонента нет — он добавляется в систему (`src/presentation/ui/`), в каталог и в этот
   документ в том же срезе, где появляется первый экран, которому он нужен. Компоненты впрок не
   пишутся.
3. Нужного токена нет — сначала проверить, не подходит ли существующий. Новый токен добавляется в
   `tokens.css`; цветовой токен для текста — с парой в `TOKEN_PAIRS`
   (`src/presentation/ui/token-pairs.ts`), тест проверяет контрастность AA.
4. «Верно» и «неверно» никогда не передаются только цветом: «верно» — сплошная рамка и галочка,
   «неверно» — пунктир и зачёркивание.
5. Интерактивный элемент не меньше `--target-size` (44×44). Фокус — `--line-thick` цвета
   `--color-focus` с отступом.
6. Тёмной темы нет: VexFlow рисует нотоносец тёмным по светлому.

Акцент и «неверно» различаются и по светлоте, и по форме (правило 4).

### Шрифты

- `--font-display` — Source Serif 4 (600, 700): заголовки `h1`–`h3`, крупные числа.
- `--font-body` — Source Sans 3 (400, 700): всё остальное.
- Шрифты в сборке из пакетов `@fontsource`, `font-display: swap`; пока грузятся — системные.
- Размеры: `--font-size-xs` 13, `-s` 14, `-m` 16, `-l` 19, `-xl` 24, `-xxl` 32,
  `-display` 64 px (в `rem`). Межстрочный — `--line-height` 1.45, `--line-height-tight` 1.15.

### Размеры

- Отступы: `--space-xs` 4, `-s` 8, `-m` 16, `-l` 24, `-xl` 32 px.
- Скругления: `--radius-s` 6, `-m` 10, `-l` 14 px, `--radius-pill`.
- Линии: `--line-thin` 1, `--line-medium` 2, `--line-thick` 3 px.
- Цели: `--target-size` 44, `--target-size-l` 52 px (основная кнопка внизу экрана),
  `--target-size-tab` 56 px (высота вкладки навигации на телефоне).
- Значки: `--icon-size` 24 px; толщина контура — `--line-medium`.
- Ширины: `--width-content` 40rem, `--width-dialog` 32rem, `--width-panel` 24rem (боковая панель «Настроить»).
- Тень: `--shadow-raised` — выбранный вариант переключателя.

## Компоненты

Появляются вместе с экранами, которым нужны (правило 2), лежат в `src/presentation/ui/` и
импортируются из `@/presentation/ui`. Кроме них система — базовые стили встроенных элементов в
`src/presentation/ui/base.css`: кнопка (обычная, `.primary`, нажатая `aria-pressed`), ссылка и
`.nav-link`, `select`, поле поиска, галка, `.screen`, `.visually-hidden`. Все компоненты с
состояниями — в разделе «Components» каталога.

### `UiCheckbox`

Галка с подписью: вся строка — цель нажатия не ниже `--target-size`.

- `v-model` — `boolean`, обязателен.
- Подпись — слот по умолчанию.
- `disabled` — неактивна: не меняется и приглушена `--opacity-disabled`.
- `aria-describedby` — уходит на саму галку, чтобы скринридер читал пояснение рядом с ней.
- Прочие атрибуты (например, `data-sound-switch`) — на корневой `label`, поэтому их находит
  `closest()` и от галки, и от подписи.

Когда применять: любая включаемая и выключаемая настройка. Не для выбора одного из нескольких
вариантов — для этого `UiSelect` или группа радиокнопок.

### `UiSelect`

Подпись и выпадающий список в одну строку; на узкой ширине список переносится под подпись.

- `label` — текст подписи, он же доступное имя списка.
- `options` — `readonly { value; label; lang? }[]`, в порядке показа; `lang` — для вариантов,
  названных на своём языке (языки, системы названий нот).
- `v-model` — `value` выбранного варианта. Компонент обобщённый: тип значения выводится из
  `options`, поэтому объединения строк (`Locale`, `NoteNaming`) проходят без приведения.

Когда применять: выбор одного из трёх и более вариантов, которые не нужно видеть все сразу.
Два-три варианта, которые важно сравнить глазами, — радиокнопки или переключатель.

### `UiSection`

Группа настроек: `section` с заголовком `h2`, связанным через `aria-labelledby`, на поверхности
`--color-surface` с рамкой `--color-line` и скруглением `--radius-l`; содержимое — столбцом с
отступом `--space-s`.

- `title` — текст заголовка.
- Содержимое — слот по умолчанию.

Когда применять: несколько связанных настроек одного экрана, по которым скринридер переходит
заголовками. Не для одиночного элемента и не для вложенных групп.

### `UiIcon`

Встроенный SVG-значок раздела по имени: контур цвета текста вокруг (`currentColor`), толщина
`--line-medium`, размер `--icon-size`, скрыт от скринридера (`aria-hidden`).

- `name` — `'trainer' | 'progress' | 'wiki' | 'settings'` (тип `IconName`): нотоносец с нотой,
  столбики диаграммы, книга, шестерёнка.

Когда применять: рядом с подписью, которая называет то же самое. Значок без подписи — нет: у него
нет доступного имени.

### `UiAppBar`

Шапка приложения: `header` (роль banner) на `--color-surface` с нижней линией `--color-line`, не
ниже `--target-size`. Слева название-ссылка шрифтом `--font-display`, справа — слот.

- `title` — текст названия, он же доступное имя ссылки.
- `to` — адрес ссылки названия.
- Навигация — слот по умолчанию, после названия.

Когда применять: одна на страницу, перед `main` и вне его, чтобы `Tab` проходил её первой. На
экране, которому нужен весь экран (вопрос сессии), её нет.

### `UiNavBar`

Навигация по разделам: `nav` с доступным именем и ссылкой на каждый пункт — значок над подписью.

- `label` — доступное имя `nav`.
- `items` — `readonly { to; label; icon; current }[]` в порядке показа. Текущий пункт задаёт
  `current`, а не адрес роутера, поэтому раздел текущий и на вложенных адресах; у его ссылки
  `aria-current="page"`, цвет `--color-accent` и жирный шрифт.
- Меньше 768 px — панель вкладок, закреплённая внизу экрана, с отступом
  `env(safe-area-inset-bottom)`: равные вкладки высотой `--target-size-tab`, у текущей — полоса
  `--line-thick` сверху. Страница сама оставляет снизу место на высоту панели (так делает
  `AppShell`). От 768 px — ссылки в строку без значков, у текущей подложка
  `--color-surface-sunken`. Разметка одна, расположение меняет CSS.

Когда применять: в слоте `UiAppBar`, одна на страницу. Не для переключения содержимого внутри
экрана — для этого переключатель или вкладки экрана.

### `UiButton`

Кнопка действия на стилях встроенной кнопки из `base.css`.

- `variant` — `'primary' | 'secondary' | 'quiet'`, по умолчанию `secondary`. `primary` — заливка
  `--color-accent`, текст `--color-on-accent`, жирный, при наведении `--color-accent-hover`;
  `secondary` — рамка `--color-border` на `--color-surface`; `quiet` — без рамки и фона.
- `size` — `'m' | 'l'`, по умолчанию `m` (не ниже `--target-size`); `l` — высота
  `--target-size-l`, текст `--font-size-l` жирный.
- `block` — во всю ширину колонки.
- `type` — по умолчанию `button`, чтобы кнопка в форме ничего не отправляла.
- `disabled` — неактивна: приглушена `--opacity-disabled`, нажатие не передаётся.
- Содержимое — слот по умолчанию, оно же доступное имя.

Когда применять: основное действие экрана (`primary`, одно на экран) и прочие действия. Не для
перехода между экранами — для этого ссылка.

### `UiOptionGrid`

Выбор одного варианта из нескольких, видимых сразу, сеткой ячеек. Нативные радиокнопки с общим
`name` внутри `role="radiogroup"`: `Tab` входит в группу на выбранном варианте и выходит из неё,
стрелки меняют выбор. Радиокнопка скрыта визуально, вся ячейка — её подпись, не ниже
`--target-size`; фокус (`:focus-visible` у радиокнопки) — кольцо на ячейке. Выбранная ячейка
залита `--color-text` с текстом `--color-surface` и жирная — не только цветом.

- `label` — доступное имя группы; видимая подпись над сеткой, если не задан `labelHidden`
  (тогда имя только для скринридера, например когда над группой уже есть такой же заголовок).
- `name` — общее имя радиокнопок, уникальное на странице (`useId()`).
- `options` — `readonly { value; label; display? }[]` в порядке показа; `label` — доступное имя
  варианта, `display` — видимая подпись, если она другая (длина «Без ограничения» видна как «∞»).
  Варианты сравниваются с выбранным значением через `===`, поэтому значения-объекты берутся из
  одного списка.
- `columns` — число колонок, по умолчанию 4; колонки равной ширины.
- `v-model` — `value` выбранного варианта; тип выводится из `options`.

Когда применять: два–восемь коротких вариантов, которые важно видеть все сразу (длина сессии).
Длинные подписи или много вариантов — `UiSelect`.

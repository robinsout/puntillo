# Дизайн-система «Нотная бумага»

Единый источник оформления Puntillo. Фича и критерии — `docs/features/design-system.md`, макеты
направления A — https://claude.ai/artifact/9viVShMqQhwxhuRf7W2NvC. Живой каталог — страница
`/design-system` в дев-сервере (`npm run dev`), в рабочую сборку не входит.

## Правила

1. Экран собирается из компонентов системы и токенов. Значения (цвета, размеры, отступы,
   скругления, тени) пишутся только в `src/presentation/ui/tokens.css`; в остальных стилях — только
   `var(--…)`. Это проверяет stylelint (`npm run lint:check`, хук перед коммитом, CI): hex,
   функции цвета, именованные цвета и `px` вне `tokens.css` запрещены; `px` допустим только в
   медиазапросах по ширине.
2. Нужного компонента нет — он добавляется в систему (`src/presentation/ui/`), в каталог и в этот
   документ в том же срезе, где появляется первый экран, которому он нужен. Компоненты впрок не
   пишутся.
3. Нужного токена нет — сначала проверить, не подходит ли существующий. Новый токен добавляется в
   `tokens.css`; цветовой токен для текста — с парой в `TOKEN_PAIRS`
   (`src/presentation/ui/token-pairs.ts`), тест проверяет контрастность AA.
4. «Верно» и «неверно» никогда не передаются только цветом: «верно» — сплошная рамка и галочка,
   «неверно» — пунктир и зачёркивание.
5. Интерактивный элемент не меньше `--target-size` (44×44). Фокус — `--line-thick` цвета
   `--color-focus` с отступом.
6. Тёмной темы нет: VexFlow рисует нотоносец тёмным по светлому.

## Токены

### Цвета

| Токен                    | Значение  | Применение                                      |
| ------------------------ | --------- | ----------------------------------------------- |
| `--color-ground`         | `#f7f2e7` | фон страницы, «бумага»                          |
| `--color-surface`        | `#fffdf8` | карточки, диалоги, панели, поля и кнопки        |
| `--color-surface-sunken` | `#ede5d3` | дорожка переключателя, утопленные области       |
| `--color-text`           | `#22201c` | основной текст, нотоносец                       |
| `--color-text-soft`      | `#4a443c` | второстепенный текст, неактивные вкладки        |
| `--color-text-muted`     | `#6b6358` | подписи, пояснения                              |
| `--color-line`           | `#e4dccb` | разделители и рамки поверхностей, без смысла    |
| `--color-border`         | `#8a7f6c` | рамки элементов управления (3:1 к поверхностям) |
| `--color-accent`         | `#8c2f39` | основное действие, текущий раздел, текущая нота |
| `--color-accent-hover`   | `#6e222b` | наведение на основное действие                  |
| `--color-accent-tint`    | `#f4e6e2` | подсветка текущего, выбранного                  |
| `--color-on-accent`      | `#fffdf8` | текст на акценте                                |
| `--color-correct`        | `#1d4e89` | «верно», верная нота                            |
| `--color-correct-tint`   | `#e8eff8` | подложка «верно»                                |
| `--color-wrong`          | `#a4470f` | «неверно», ответ пользователя                   |
| `--color-wrong-tint`     | `#fbede3` | подложка «неверно»                              |
| `--color-focus`          | `#1d4e89` | кольцо фокуса                                   |
| `--color-scrim`          | 40 % тона | затемнение под диалогом                         |

Акцент и «неверно» различаются и по светлоте, и по форме (правило 4).

### Шрифты

- `--font-display` — Source Serif 4 (600, 700): заголовки `h1`–`h3`, крупные числа.
- `--font-body` — Source Sans 3 (400, 700): всё остальное.
- Шрифты в сборке из пакетов `@fontsource`, `font-display: swap`; пока грузятся — системные.
- Размеры: `--font-size-xs` 13, `-s` 14, `-m` 16, `-l` 19, `-xl` 24, `-xxl` 32,
  `-display` 64 px (в `rem`). Межстрочный — `--line-height` 1.45, `--line-height-tight` 1.15.

### Размеры

- Отступы: `--space-xs` 4, `-s` 8, `-m` 16, `-l` 24, `-xl` 32 px.
- Скругления: `--radius-s` 6, `-m` 10, `-l` 14 px, `--radius-pill`.
- Линии: `--line-thin` 1, `--line-medium` 2, `--line-thick` 3 px.
- Цели: `--target-size` 44, `--target-size-l` 52 px (основная кнопка внизу экрана).
- Ширины: `--width-content` 40rem, `--width-dialog` 32rem, `--width-panel` 24rem (боковая панель «Настроить»).
- Тень: `--shadow-raised` — выбранный вариант переключателя.

## Компоненты

Появляются вместе с экранами, которым нужны (правило 2). Пока система — токены и базовые стили
встроенных элементов в `src/presentation/ui/base.css`: кнопка (обычная, `.primary`, нажатая
`aria-pressed`), ссылка и `.nav-link`, `select`, поле поиска, галка, `.screen`, `.visually-hidden`.

# Дизайн-система «Нотная бумага»

Единый источник оформления Puntillo. Фича и критерии — `docs/features/design-system.md`, макеты
направления A — https://claude.ai/artifact/9viVShMqQhwxhuRf7W2NvC. Живой каталог — страница
`/design-system` в дев-сервере (`npm run dev`), в рабочую сборку не входит.

## Правила

1. Экран собирается из компонентов системы и токенов. Значения (цвета, размеры, отступы,
   скругления, тени) пишутся только в `src/presentation/ui/tokens.css`; в остальных стилях — только
   `var(--…)`. Это проверяет stylelint (`npm run lint:check`, хук перед коммитом, CI): hex,
   функции цвета, именованные цвета и `px` вне `tokens.css` запрещены; `px` допустим только в
   медиазапросах по ширине.
2. Нужного компонента нет — он добавляется в систему (`src/presentation/ui/`), в каталог и в этот
   документ в том же срезе, где появляется первый экран, которому он нужен. Компоненты впрок не
   пишутся.
3. Нужного токена нет — сначала проверить, не подходит ли существующий. Новый токен добавляется в
   `tokens.css`; цветовой токен для текста — с парой в `TOKEN_PAIRS`
   (`src/presentation/ui/token-pairs.ts`), тест проверяет контрастность AA.
4. «Верно» и «неверно» никогда не передаются только цветом: «верно» — сплошная рамка и галочка,
   «неверно» — пунктир и зачёркивание.
5. Интерактивный элемент не меньше `--target-size` (44×44). Фокус — `--line-thick` цвета
   `--color-focus` с отступом.
6. Тёмной темы нет: VexFlow рисует нотоносец тёмным по светлому.

### Шрифты

- `--font-display` — Source Serif 4 (600, 700): заголовки `h1`–`h3`, крупные числа.
- `--font-body` — Source Sans 3 (400, 700): всё остальное.
- Шрифты в сборке из пакетов `@fontsource`, `font-display: swap`; пока грузятся — системные.
- Размеры: `--font-size-xs` 13, `-s` 14, `-m` 16, `-l` 19, `-xl` 24, `-xxl` 32,
  `-display` 64 px (в `rem`). Межстрочный — `--line-height` 1.45, `--line-height-tight` 1.15.

### Размеры

- Отступы: `--space-xs` 4, `-s` 8, `-m` 16, `-l` 24, `-xl` 32 px.
- Скругления: `--radius-s` 6, `-m` 10, `-l` 14 px, `--radius-pill`.
- Линии: `--line-thin` 1, `--line-medium` 2, `--line-thick` 3 px; `--line-progress` 6 px — толщина
  полосы прогресса.
- Цели: `--target-size` 44, `--target-size-l` 52 px (основная кнопка внизу экрана),
  `--target-size-tab` 56 px (высота вкладки навигации на телефоне).
- Значки: `--icon-size` 24 px, `--icon-size-s` 16 px (галочка на клавише ответа); толщина контура —
  `--line-medium`.
- Ширины: `--width-content` 40rem, `--width-dialog` 32rem, `--width-panel` 24rem (боковая панель «Настроить»),
  `--width-example` 5rem (нотоносец примера на карточке пресета), `--width-wide` 62.5rem (колонка
  экрана вопроса на широком экране), `--width-choice-text` 5rem (самая узкая часть `UiChoiceCard` с
  текстом и отметкой рядом с картинкой), `--width-option` 4rem (самая узкая ячейка `UiOptionGrid`).
  Обе в `rem`, поэтому при крупном тексте браузера карточка ставит картинку над текстом, а сетка
  переносит ячейки на новые строки.
- Тени: `--shadow-raised` — выбранный вариант переключателя; `--shadow-dialog` — диалог по центру.
- Движение: `--duration-enter` 0.2 s — появление диалога. При системной настройке «уменьшить
  движение» все переходы и анимации обнуляет общее правило `base.css`.

## Компоненты

Появляются вместе с экранами, которым нужны (правило 2), лежат в `src/presentation/ui/` и
импортируются из `@/presentation/ui`. Кроме них система — базовые стили встроенных элементов в
`src/presentation/ui/base.css`: кнопка (обычная, `.primary`, нажатая `aria-pressed`), ссылка и
`.nav-link`, `select`, галка, `.screen`, `.visually-hidden`, клавиша `.ui-kbd` (клавиша
компьютера в `<kbd>`: рамка `--line-thin` `--color-border`, скругление `--radius-s`, текст
`--font-size-s`). Все компоненты с
состояниями — в разделе «Components» каталога.

### `UiCheckbox`

Галка с подписью: вся строка — цель нажатия не ниже `--target-size`.

- `v-model` — `boolean`, обязателен.
- Подпись — слот по умолчанию.
- `disabled` — неактивна: не меняется и приглушена `--opacity-disabled`.
- `aria-describedby` — уходит на саму галку, чтобы скринридер читал пояснение рядом с ней.
- Прочие атрибуты (например, `data-sound-switch`) — на корневой `label`, поэтому их находит
  `closest()` и от галки, и от подписи.

Когда применять: любая включаемая и выключаемая настройка. Не для выбора одного из нескольких
вариантов — для этого `UiSelect` или группа радиокнопок.

### `UiSelect`

Подпись и выпадающий список в одну строку; на узкой ширине список переносится под подпись.

- `label` — текст подписи, он же доступное имя списка.
- `options` — `readonly { value; label; lang?; disabled? }[]`, в порядке показа; `lang` — для
  вариантов, названных на своём языке (языки, системы названий нот); `disabled` — вариант нельзя
  выбрать, причину называет его же текст («do5 — Too few notes»): вариант списка ничего другого
  нести не может.
- `stacked` — список под подписью во всю ширину колонки, а не рядом: для узкой колонки и для
  вариантов с длинным текстом («From», «To»).
- Слот `aside` — сразу после подписи, перед списком (справка «?» параметра).
- `aria-describedby` — уходит на сам `<select>`, чтобы скринридер читал строку рядом со списком
  (состояние микрофона под «Note input»).
- `v-model` — `value` выбранного варианта. Компонент обобщённый: тип значения выводится из
  `options`, поэтому объединения строк (`Locale`, `NoteNaming`) проходят без приведения.

Когда применять: выбор одного из трёх и более вариантов, которые не нужно видеть все сразу.
Два-три варианта, которые важно сравнить глазами, — радиокнопки или переключатель.

### `UiSection`

Группа настроек: `section` с заголовком `h2`, связанным через `aria-labelledby`, на поверхности
`--color-surface` с рамкой `--color-line` и скруглением `--radius-l`; содержимое — столбцом с
отступом `--space-s`.

- `title` — текст заголовка.
- Содержимое — слот по умолчанию.

Когда применять: несколько связанных настроек одного экрана, по которым скринридер переходит
заголовками. Не для одиночного элемента и не для вложенных групп.

### `UiIcon`

Встроенный SVG-значок раздела по имени: контур цвета текста вокруг (`currentColor`), толщина
`--line-medium`, размер `--icon-size`, скрыт от скринридера (`aria-hidden`).

- `name` — `'trainer' | 'progress' | 'wiki' | 'settings' | 'check' | 'close' | 'cross' |
'chevron' | 'back'` (тип `IconName`): нотоносец с нотой, столбики диаграммы, книга, шестерёнка,
  круг с галочкой (отметка выбранной карточки, «верно»), × («Завершить»), × в круге («неверно»),
  › (конец строки `UiLinkList`), ‹ (тихая ссылка назад, «‹ Wiki»).
- `size` — `'m' | 's'`, по умолчанию `m` (`--icon-size`); `s` — `--icon-size-s`, рядом с текстом
  клавиши.

Когда применять: рядом с подписью, которая называет то же самое. Значок без подписи — только внутри
кнопки с доступным именем (`aria-label`), как × у «Завершить».

### `UiAppBar`

Шапка приложения: `header` (роль banner) на `--color-surface` с нижней линией `--color-line`, не
ниже `--target-size`. Слева название-ссылка шрифтом `--font-display`, справа — слот.

- `title` — текст названия, он же доступное имя ссылки.
- `to` — адрес ссылки названия.
- Навигация — слот по умолчанию, после названия.

Когда применять: одна на страницу, перед `main` и вне его, чтобы `Tab` проходил её первой. На
экране, которому нужен весь экран (вопрос сессии), её нет.

### `UiLogo`

Знак приложения — нота с точкой на акцентном квадрате, тот же, что `public/favicon.svg`. Встроенный
SVG, скрыт от скринридера (`aria-hidden`), без props. Квадрат — `--color-accent`, нота —
`--color-surface`. Размер `1.1em`, поэтому растёт вместе с текстом рядом.

Когда применять: перед названием внутри ссылки в `UiAppBar`. Сам по себе не интерактивен и без
подписи рядом не используется: имя даёт текст.

### `UiNavBar`

Навигация по разделам: `nav` с доступным именем и ссылкой на каждый пункт — значок над подписью.

- `label` — доступное имя `nav`.
- `items` — `readonly { to; label; icon; current }[]` в порядке показа. Текущий пункт задаёт
  `current`, а не адрес роутера, поэтому раздел текущий и на вложенных адресах; у его ссылки
  `aria-current="page"`, цвет `--color-accent` и жирный шрифт.
- Меньше 768 px — панель вкладок, закреплённая внизу экрана, с отступом
  `env(safe-area-inset-bottom)`: равные вкладки высотой `--target-size-tab`, у текущей — полоса
  `--line-thick` сверху. Страница сама оставляет снизу место на высоту панели (так делает
  `AppShell`). От 768 px — ссылки в строку без значков, у текущей подложка
  `--color-surface-sunken`. Разметка одна, расположение меняет CSS.

Когда применять: в слоте `UiAppBar`, одна на страницу. Не для переключения содержимого внутри
экрана — для этого переключатель или вкладки экрана.

### `UiButton`

Кнопка действия на стилях встроенной кнопки из `base.css`.

- `variant` — `'primary' | 'secondary' | 'quiet'`, по умолчанию `secondary`. `primary` — заливка
  `--color-accent`, текст `--color-on-accent`, жирный, при наведении `--color-accent-hover`;
  `secondary` — рамка `--color-border` на `--color-surface`; `quiet` — без рамки и фона.
- `size` — `'m' | 'l'`, по умолчанию `m` (не ниже `--target-size`); `l` — высота
  `--target-size-l`, текст `--font-size-l` жирный.
- `block` — во всю ширину колонки.
- `type` — по умолчанию `button`, чтобы кнопка в форме ничего не отправляла.
- `disabled` — неактивна: приглушена `--opacity-disabled`, нажатие не передаётся.
- Содержимое — слот по умолчанию, оно же доступное имя.
- `to` — адрес: тогда это ссылка `RouterLink` с видом той же кнопки («Read the article» в
  подсказке), событие `click` сохраняется.
- `focus()` — открыт через `ref`, чтобы вернуть фокус кнопке, открывшей диалог.

Когда применять: основное действие экрана (`primary`, одно на экран) и прочие действия. Не для
перехода между экранами — для этого ссылка.

### `UiOptionGrid`

Выбор одного варианта из нескольких, видимых сразу, сеткой ячеек. Нативные радиокнопки с общим
`name` внутри `role="radiogroup"`: `Tab` входит в группу на выбранном варианте и выходит из неё,
стрелки меняют выбор. Радиокнопка прозрачна и лежит поверх всей ячейки, ячейка — её подпись, не ниже
`--target-size`; фокус (`:focus-visible` у радиокнопки) — кольцо на ячейке. Выбранная ячейка
залита `--color-text` с текстом `--color-surface` и жирная — не только цветом.

- `label` — доступное имя группы; видимая подпись над сеткой, если не задан `labelHidden`
  (тогда имя только для скринридера, например когда над группой уже есть такой же заголовок).
- `name` — общее имя радиокнопок, уникальное на странице (`useId()`).
- `options` — `readonly { value; label; display?; disabled?; description? }[]` в порядке показа;
  `label` — доступное имя варианта, `display` — видимая подпись, если она другая (длина «Без
  ограничения» видна как «∞»). `disabled` — вариант нельзя выбрать, ячейка приглушена
  `--opacity-disabled`; `description` — причина, вторичным мелким текстом под ячейкой и доступным
  описанием радиокнопки (`aria-describedby`); в имя варианта она не входит.
  Варианты сравниваются с выбранным значением через `===`, поэтому значения-объекты берутся из
  одного списка.
- `columns` — число колонок, по умолчанию 4; колонки равной ширины.
- `v-model` — `value` выбранного варианта; тип выводится из `options`.

Когда применять: два–восемь коротких вариантов, которые важно видеть все сразу (длина сессии).
Длинные подписи или много вариантов — `UiSelect`.

### `UiSegmented`

Переключатель из нескольких сегментов в одну строку во всю ширину колонки. Нативные радиокнопки с
общим `name` в `fieldset`, подпись — `legend`, скрытая визуально: `Tab` входит в группу на
выбранном варианте, стрелки меняют выбор. Дорожка `--color-surface-sunken`, сегменты равной
ширины, не ниже `--target-size`; выбранный — поверхность `--color-surface` с `--shadow-raised` и
жирным текстом, не только цветом. Фокус — кольцо на сегменте.

- `label` — доступное имя группы, видно только скринридеру.
- `name` — общее имя радиокнопок, уникальное на странице (`useId()`).
- `options` — `readonly { value; label; disabled?; description? }[]` в порядке показа; `label` —
  подпись сегмента. `disabled` и `description` — как у `UiOptionGrid`: причина под сегментом.
- `v-model` — `value` выбранного варианта; тип выводится из `options`.

Когда применять: два–четыре коротких взаимоисключающих варианта в одну строку («Упражнение»,
«Добавочные линейки», «Ключевые знаки»). Длинные подписи — `UiOptionGrid`.

### `UiChoiceCard`

Карточка выбора одного из немногих: кнопка `type="button"` с `aria-pressed`. Слева слот `media`,
затем название жирным и строка описания `--color-text-muted`, справа у выбранной — отметка
`UiIcon check` цвета `--color-accent` (скрыта от скринридера). Рамка `--line-thin`
`--color-border`, у выбранной — `--line-medium` `--color-accent`; скругление `--radius-l`,
во всю ширину колонки.

- `pressed` — выбрана ли карточка.
- `title` — название, оно же единственное доступное имя (`aria-labelledby`), что бы ни было в
  `media`.
- `description` — строка под названием, она же доступное описание (`aria-describedby`).
- `describedBy` — id других описаний вне карточки, читаются после её строки (пометка «Изменено»).
- Слот `media` — картинка слева шириной `--width-example`; без слота карточка без картинки.
- Событие `click`.

Когда применять: выбор одного из двух-четырёх вариантов, которым нужно пояснение или пример
(пресеты уровня). Короткие варианты без пояснений — `UiSegmented` или `UiOptionGrid`.

Примеры на карточках пресетов — готовые SVG `src/presentation/preferences/preset-examples/<пресет>.svg`,
снятые с настоящего `StaffView` (раздел «Preset examples» каталога), чтобы стартовый экран не
загружал VexFlow. Глифы Bravura в них — контуры, цвет — `currentColor`, то есть `--color-text`
карточки. После изменения `PRESET_EXAMPLES`, `StaffView.vue` или версии VexFlow рисунки
перегенерируются командой `npm run render:examples`; без этого модульный тест сообщает, что они
устарели (отпечаток исходных данных — атрибут `data-source` у корня рисунка).

### `UiProgress`

Полоса прогресса: `role="progressbar"` от 0 до `max`, заливка `--color-accent` по дорожке
`--color-line`, толщина `--line-progress`, концы скруглены.

- `value` — текущее значение (`aria-valuenow`), заливка — его доля от `max`.
- `max` — наибольшее значение (`aria-valuemax`).
- `label` — доступное имя полосы. Видимую подпись («1 / 10») экран ставит рядом сам.

Когда применять: ход чего-то конечного — вопросы сессии, время сессии на время. Без предела
(«Без ограничения») полосы нет — только текст.

### `UiAnswerKey`

Клавиша ответа: кнопка `type="button"` с `aria-pressed` на стилях встроенной кнопки; содержимое —
слот, оно же доступное имя (или `aria-label`, если в слоте знак: ♯ — «Диез»). Подпись клавиши
компьютера (`KeyCaption`) — в правом верхнем углу, кнопка позиционирована.

- `pressed` — выбрана: залита `--color-text`, текст `--color-surface`, жирный.
- `mark` — `'correct' | 'wrong' | 'rejected' | null` (тип `AnswerMark`), отдаётся атрибутом
  `data-mark`:
  - `correct` — сплошная рамка `--color-correct` толще обычной, подложка `--color-correct-tint`,
    жирный, галочка `UiIcon check` размера `s` (скрыта от скринридера; узкая клавиша переносит её
    под название);
  - `wrong` — пунктир `--color-wrong`, подложка `--color-wrong-tint`, зачёркнуто, жирный;
  - `rejected` (отклонено в первой попытке) — пунктир и зачёркивание, бледно, как неактивная.
    Помеченные `correct` и `wrong` видны в полную силу и неактивными.
- `disabled` — неактивна: `--opacity-disabled`, нажатие не передаётся.
- Прочие атрибуты (`aria-describedby` пометки, `aria-keyshortcuts`, `lang`) — на кнопку.
- Событие `click`.

Когда применять: варианты ответа на вопрос — названия нот, знаки, длительности. Клавиши
фортепиано — своя форма в `PianoKeyboard`, с теми же `data-mark` и тем же языком пометок.

### `UiTextField`

Однострочное поле с подписью над ним: подпись — `label`, она же доступное имя поля. Поле во всю
ширину, не ниже `--target-size`, рамка `--color-border`, поверхность `--color-surface`, фокус по
системе.

- `label` — текст подписи.
- `type` — `'text' | 'search'`, по умолчанию `text`; `search` — поле поиска (роль `searchbox`).
- `v-model` — `string`, обязателен.

Когда применять: ввод короткого текста — поиск по справке. Выбор из готовых вариантов — не поле, а
`UiSelect` или радиокнопки.

### `UiList`

Список на поверхности: `ul` на `--color-surface` с рамкой `--color-line` и скруглением
`--radius-l`, строки (`li` из слота) через разделитель `--color-line`. Отступы строк задаёт тот, кто
их кладёт.

- Строки — слот по умолчанию.
- Прочие атрибуты (`aria-labelledby`) — на `ul`.

Когда применять: перечень однородных строк экрана — недавние сессии, трудные ноты, ошибки итога.
Пустой перечень — не пустой список, а строка вторичного текста.

### `UiLinkList`

Список ссылок-строк на `UiList`: каждая ссылка — строка во всю ширину списка, не ниже
`--target-size`, название слева, справа `UiIcon chevron` (`aria-hidden`, имя ссылки — только
название). Без подчёркивания, наведение — подложка `--color-surface-sunken`, фокус — внутри строки.
Длинное название переносится.

- `items` — `readonly { to; label }[]`, в порядке показа; `to` — адрес `RouterLink`.

Когда применять: переход к одному из нескольких разделов или статей — темы справки, «See also».
Ссылка внутри предложения или одиночная ссылка назад — обычная ссылка (`.nav-link`).

### `UiStat`

Плитка показателя: пара `dt` (подпись) и `dd` (значение) в обёртке `div` — ставится внутрь `dl`,
который задаёт раскладку плиток. Поверхность `--color-surface`, рамка `--color-line`, скругление
`--radius-m`; подпись `--font-size-s` цвета `--color-text-muted`, значение `--font-size-xl` жирным.

- `label` — подпись, термин `dt`.
- `value` — значение, строка или число; вместо него — слот по умолчанию для значения с разметкой.

Когда применять: несколько коротких числовых показателей рядом (итог сессии: вопросы, лучшая серия,
среднее время). Главное число экрана (точность) — не плитка, а крупный текст шрифтом
`--font-display`.

### `UiDialog`

Диалог: нативный `<dialog>`, открытый `showModal()` — фокус остаётся внутри, `Esc` закрывает.
Заголовок `h2` шрифтом `--font-display` — доступное имя (`aria-labelledby`); содержимое
прокручивается между заголовком и действиями, действия всегда видны. Подложка `--color-scrim`;
появление — короткое проявление за `--duration-enter`, без сдвига.

- `title` — текст заголовка.
- `variant` — `'center' | 'sheet'`, по умолчанию `center`. `center` — по центру, ширина
  `--width-dialog` (не шире экрана без отступов `--space-m`), поверхность `--color-surface`,
  скругление `--radius-l`, тень `--shadow-dialog`, отступы `--space-l`. `sheet` — меньше 768 px
  нижняя панель во всю ширину со скруглением сверху, над ней полоса подложки высотой
  `--target-size`; от 768 px — боковая панель справа шириной `--width-panel` во всю высоту.
  Действия у `sheet` отделены линией `--color-line` и прилипают к низу панели, с отступом
  `env(safe-area-inset-bottom)`.
- `v-model:open` — открыт ли. Содержимое рендерится только пока открыт.
- Событие `close` — при любом закрытии: `Esc`, нажатие на подложку, значение `false`.
- Содержимое — слот по умолчанию; кнопки — слот `actions`, после содержимого, справа.
- Прочие атрибуты (`aria-describedby`) — на `<dialog>`.

Фокус открывшей кнопке возвращает экран в обработчике `close`: не каждый движок делает это сам.

Когда применять: подсказка, подтверждение, справочная таблица — `center`; панель настроек с
длинным списком значений — `sheet`. Подтверждение: основное действие `UiButton primary`, отмена —
`secondary`; нажатие на подложку — та же отмена.

### `UiDisclosure`

Раскрывающаяся группа: кнопка-заголовок во всю ширину колонки (шрифт `--font-display`,
`--font-size-l`, линия `--color-line` снизу) с `aria-expanded` и `aria-controls`, справа
`UiIcon chevron`, повёрнутый вниз у раскрытой (скрыт от скринридера). Свёрнутое содержимое не
рендерится.

- `title` — текст заголовка, он же единственное доступное имя кнопки.
- `v-model` — `boolean`, раскрыта ли.
- Содержимое — слот по умолчанию, столбцом с отступом `--space-m`.

Когда применять: группы настроек длинной панели, из которых обычно нужна одна («Высота», «Ритм»,
«Знаки» в «Настроить»). Короткий экран настроек — `UiSection`, всё видно сразу.

### `UiIconButton`

Круглая кнопка `type="button"` размером `--target-size` со знаком внутри, на стилях встроенной
кнопки.

- `label` — обязательное доступное имя (`aria-label`): знак ничего не говорит скринридеру.
- Знак — слот по умолчанию: символ («?») или `UiIcon`.
- Событие `click` — с событием нажатия, `currentTarget` — сама кнопка (чтобы вернуть ей фокус).

Когда применять: действие, понятное по знаку рядом с тем, к чему оно относится, — справка «?»
параметра. Действие со словом — `UiButton`.
